# Portfolio Template

A responsive four-page portfolio built with Next.js, Tailwind CSS, and the linked Figma design.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home and recent articles
- `/about` — About and social links
- `/projects` — Selected projects
- `/uses` — Recommended tools and equipment

Use the theme button in the header to switch between light and dark modes. The selection is saved in the browser.

Build and run the production version:

```bash
npm run build
npm run start
```

The newsletter form currently provides client-side feedback; connect it to a mailing-list provider before using it for subscriptions.
